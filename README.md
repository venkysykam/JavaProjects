# Java Programming Practice 🚀

This repository contains my Java practice programs organized topic-wise. It covers fundamental to intermediate concepts, helping in building a strong foundation in Java programming.

## 📂 Project Structure

- **Arrays** → Programs related to array operations
- **Strings** → String manipulation and problem-solving
- **Bitwise Operations** → Bit-level operations and examples
- **Conditional Statements** → if, switch, and decision-making programs
- **Conditional Loops** → for, while, do-while loops
- **Object Oriented Programming** → OOP concepts like classes, objects, inheritance, polymorphism

## 💡 Features

- Clean and simple Java programs
- Beginner-friendly examples
- Topic-wise organization
- Useful for interview preparation and practice

## 🛠 Technologies Used

- Java
- JDK (Java Development Kit)
